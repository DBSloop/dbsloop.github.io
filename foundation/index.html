Design tokens

One place, two themes.

Every colour, size, radius, shadow and duration on this site is written once, in one file — src/styles/tokens.css — and Tailwind gives them names without restating a single value. Change a number there and it changes here, in both themes, with no second edit.

The guarantee

Your credentials never leave your machine. No telemetry, no analytics, no update pings. cargo tree on this repo shows no HTTP client in the dependency graph — there is nothing in the binary that could phone home.

03

Terminal

JetBrains Mono, self-hosted, ligatures off so an arrow in a command is two characters and not one glyph. Every terminal block on this site is real HTML text — selectable, copyable, searchable and readable by a crawler. Never an image.
